# Workflow Organising Tool

The project was supposed to use [Themed] Tkinter library in Python. However, it quickly overwhelmed me and forced me to look for an alternative. That is how I ended up using *toga* (🐂)|.

This project is for organising my projects (as the name spoils). Inspired by this article: https://medium.com/@roylowrance/how-i-organize-my-file-system-8b6f98ed4b43
